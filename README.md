# 🪷 大六壬排盘工具

纯前端大六壬课式排盘工具，基于月将、占时自动演算天地盘、四课、三传，一键复制课式给 AI 解读，并提供推导教程帮助初学者理解排盘逻辑。

在线地址: [https://daliuren-pp.pages.dev](https://daliuren-pp.pages.dev)  
源码: [https://github.com/Zzx-LiU6/daliuren](https://github.com/Zzx-LiU6/daliuren)

---

## 🧠 为什么做这个项目

这个项目基于已有的排盘方案（`liuren-ts-lib`），我的主要工作并不是重新设计排盘算法，而是将已有功能重新组织为更清晰的界面。

六壬排盘本身包含大量专业信息——天地盘、四课、三传、神煞、遁干、贵人……对于初学者来说，面对一张完整的课式往往不知道从何看起。

因此，这个项目的核心目标是：

> **当核心功能已经存在时，如何通过界面和信息组织降低用户的理解成本。**

这是一个和“从零设计产品”不同的问题——我需要做的是“翻译”和“重构”，而不是“发明”。

---

## ⚖️ 重要设计取舍

- **依赖第三方排盘库，而非自己实现算法**
  - 大六壬的排盘逻辑涉及复杂的月将计算、昼夜贵人起法、遁干规则等，自己实现一套完整算法的时间成本极高。
  - 使用成熟的 `liuren-ts-lib` 库可以快速获得准确的排盘结果，让我把精力集中在 UI/UX 设计上。
  - 代价是对外部库有一定依赖，如果库有 bug 或 API 变更，需要及时跟进。

- **双视图模式：课式结果 + 推导教程**
  - 大部分排盘工具只展示最终课式，但对初学者来说，“看到结果”和“理解为什么得出这个结果”之间存在鸿沟。
  - 增加“推导教程”视图，将排盘过程拆解为 7 步（月将 → 天地盘 → 遁干 → 四课 → 三传 → 阴阳贵人 → 课式总览），每一步都附有说明。
  - 这样既满足了“快速排盘”的需求，也满足了“学习排盘逻辑”的需求，两种用户都能覆盖。

- **自动适配当前时间 + 支持手动修改**
  - 打开页面即自动获取当前时间作为占时，降低首次使用门槛。
  - 同时保留月将和占时的手动修改能力，满足需要指定特定时间的进阶用户。

- **课式 + AI 提示词一键复制**
  - 参考六爻工具的设计思路，同样提供一键复制完整课式 + AI 解读提示词模板。
  - 让用户从“排盘”到“解读”的路径更短，无需手动整理课式文本。

## 🚧 已知局限与未来计划

- **排盘规则的可配置性**：目前基于 `liuren-ts-lib` 的默认规则（如贵人起法），暂不支持不同流派的规则切换（如不同贵人起例）。后续可考虑增加规则配置选项。

- **神煞的完整度**：目前展示的是核心神煞，部分更细粒度的神煞尚未完全覆盖。后续可根据用户反馈逐步补充。

- **推导教程的交互深度**：目前的“推导教程”是静态的文字说明 + 对应步骤的展示。未来可以考虑做成“逐步交互式教程”——用户每点击一步，界面动态展示该步骤的计算过程，让学习体验更加沉浸。

## ✨ 主要功能

- **双视图模式**：「课式结果」完整展示天地盘、四课、三传、神煞 / 「推导教程」分步拆解排盘逻辑，适合学习大六壬的初学者
- **七步推演教程**：月将 → 天地盘 → 遁干 → 四课 → 三传 → 阴阳贵人 → 课式总览，每一步都附有清晰说明
- **自动演算三传与课体**：支持元首、重审、遥克、反吟、伏吟等多种课体识别
- **一键复制完整课式**：自带 AI 解读提示词模板，可直接粘贴给 ChatGPT、DeepSeek、Claude 等 AI 平台解读
- **自动适配当前时间**：打开即用，支持手动修改占时
- **无需注册、无后端、无广告**：所有运算在本地完成，隐私安全

## 🛠 技术栈

- 原生 JavaScript（ES Module）
- 原生 CSS3，响应式暗色主题
- 大六壬排盘核心库：[liuren-ts-lib](https://github.com/look-fate/liuren-ts-lib)（通过 esm.sh CDN 加载）
- Cloudflare Pages（部署托管）

## 🚀 本地运行

本项目为纯静态 HTML 项目，无需安装依赖、无需构建命令。克隆后直接用浏览器打开 `index.html` 即可。

```bash
git clone https://github.com/Zzx-LiU6/daliuren.git
cd daliuren
# 直接用浏览器打开 index.html
```

## 📖 使用流程

1. 打开页面，系统自动获取当前时间作为占时
2. 如需手动调整，修改月将或占时
3. 系统自动演算天地盘、四课、三传
4. 切换「课式结果」查看完整课盘，或切换「推导教程」学习排盘逻辑
5. 一键复制课式 + AI 提示词模板
6. 粘贴到 AI 平台获取解读
