# 🪷 大六壬排盘工具

纯前端大六壬课式排盘工具，基于月将、占时自动演算天地盘、四课、三传，一键复制课式给 AI 解读，并提供推导教程帮助初学者理解排盘逻辑。

在线地址: https://daliuren-pp.pages.dev

## 主要功能

- 双视图模式：「课式结果」完整展示天地盘、四课、三传、神煞 / 「推导教程」分步拆解排盘逻辑，适合学习大六壬的初学者
- 七步推演教程：月将 → 天地盘 → 遁干 → 四课 → 三传 → 阴阳贵人 → 课式总览，每一步都附有清晰说明
- 自动演算三传与课体（元首、重审、遥克、反吟、伏吟等）
- 一键复制完整课式，自带 AI 解读提示词
- 自动适配当前时间，支持手动修改
- 无需注册、无后端、无广告，所有运算在本地完成

## 技术栈

- 原生 JavaScript（ES Module）
- 原生 CSS3，响应式暗色主题
- 大六壬排盘核心库：[liuren-ts-lib](https://github.com/look-fate/liuren-ts-lib)（通过 esm.sh CDN 加载）
- Cloudflare Pages（部署托管）

## 本地运行

本项目为纯静态 HTML 项目，无需安装依赖、无需构建命令。

# 或使用本地服务器
npx serve .
